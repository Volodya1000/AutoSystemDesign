# BRD: регистрация и отслеживание заказа

## Назначение

Интернет-магазин предоставляет покупателю регистрацию заказа и просмотр его
текущего статуса. Это отдельный сервис учёта заказов; оплата и управление
складом находятся за границами этого примера.

## Функциональные требования

FR-001. Система должна регистрировать заказ покупателя по списку кодов товаров
и их количеств с возвратом уникального номера заказа.

FR-002. Система должна возвращать текущий статус заказа по его номеру.

## Нагрузка и ограничения

Обычная нагрузка составляет 120 запросов в секунду, пиковая — 400 запросов в
секунду. Доля запросов чтения составляет 80%, доля записи — 20%.

При обычной нагрузке 95-й перцентиль времени ответа API не должен превышать
300 миллисекунд.

Месячный бюджет инфраструктуры не должен превышать 500 долларов США.
