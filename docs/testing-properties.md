# Property-based тестирование с Hypothesis

Помимо обычных unit-тестов используются проверки инвариантов, где Hypothesis генерирует разные допустимые и недопустимые комбинации параметров.

Первый набор независимых свойств:

- отношение чтений и записей дополняется до 1;
- пиковая нагрузка не может быть ниже базовой;
- интервалы принимают границы и отклоняют значения за ними;
- идентификаторы артефактов соответствуют правилам безопасности путей.

```bash
uv sync --locked --all-groups
uv run --with hypothesis==6.170.2 pytest property_tests -q
uv run --with hypothesis==6.170.2 mypy --strict property_tests
```

Свойства вынесены в `property_tests/`, чтобы обычный запуск `pytest tests/unit` не требовал новой зависимости вне `uv.lock`. Отдельный обязательный workflow запускает Hypothesis на каждом PR и в `master`.

Каждый тест определяет **наблюдаемый инвариант**, а не сравнивает текст диаграммы или детали внутренней реализации. Найденные контрпримеры Hypothesis упрощает до минимальных воспроизводимых случаев.
