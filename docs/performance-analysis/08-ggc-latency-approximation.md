# Аппроксимация G/G/c для средней задержки

## Что рассчитывается

Модель оценивает среднее время ожидания и среднее время ответа. Это не точная M/M/c: здесь применяется аппроксимация Allen–Cunneen с вариативным временем обслуживания. Для входящего потока без отдельного параметра вариативности принимается пуассоновское допущение \(c_a^2=1\).

Число независимых каналов задаётся явно: replicas_count × service_channels_per_replica. maximum_concurrency используется для пропускной способности, но не считается числом серверов очереди.

## Формула

\[
\rho = \frac{\lambda E[S]}{c}
\]

\[
W_q \approx \frac{c_a^2+c_s^2}{2}
\frac{\rho^{\sqrt{2(c+1)}-1}}{c(1-\rho)} E[S]
\]

\[
W = W_q + E[S]
\]

Здесь \(\lambda\) — интенсивность входящего потока, \(E[S]\) — среднее время обслуживания, \(c\) — число независимых каналов, \(c_s^2=\sigma_S^2/E[S]^2\). Если среднее задано в миллисекундах, интенсивность одного канала равна \(1000/E[S]\) запросов/с.

## Проверка и ограничения

При одном канале и пуассоновском потоке формула сводится к формуле Поллачека — Хинчина для M/G/1. При экспоненциальном обслуживании \(c_s^2=1\), результат совпадает с точной M/M/1. При \(c>1\) Allen–Cunneen остаётся аппроксимацией, а точная M/M/c-модель с формулой Эрланга C реализована отдельно.

Если число каналов неизвестно, статистические параметры некорректны или \(\rho \geq 1\), оценка недоступна и сериализуется как null. При нулевой нагрузке ожидание равно нулю. Критический путь строится только по синхронным рёбрам от клиентских узлов; асинхронный вызов не увеличивает задержку вызывающего запроса.

Среднее время ответа не подтверждает и не опровергает p95/p99. Процентильные требования остаются неоценёнными до появления модели распределения времени ответа и достаточных входных данных.
