# Язык подписей артефактов

В `config.yaml`:

```yaml
generation:
  artifact_language: ru
```

Поддерживаются `ru` и `en`. В поставляемом примере включён русский; при отсутствии
поля сохраняется прежний английский язык. Переменная окружения:
`ASD_GENERATION__ARTIFACT_LANGUAGE=ru`.

Одна политика передаётся генераторам C4, ролей, Sequence и API, включая все
повторные попытки исправления. Требуются короткие заголовки и действия вместо
повторения полного требования. В C4 `display_name` хранится отдельно от `identifier`:
картинка может показывать «Сервис заказов», а ссылки остаются `orders_api`.
При отсутствии имени для старого графа используется технический ID.

Идентификаторы, URI, HTTP-методы, ключи JSON и значения перечислений не переводятся.
Фиксированные технические метки и элементы интерфейса сторонних библиотек
(например Swagger UI и легенда C4-PlantUML) имеют собственную локализацию.

Политика языка — инструкция модели, а не доказательство корректного перевода.
Проверять язык по наличию кириллицы нельзя: это не устанавливает смысл и полноту.
После реального прогона нужна ручная проверка названий и читаемости изображений.
