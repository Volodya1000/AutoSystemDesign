# Этап 6A: альтернативные маршруты и cache hit/miss

## Один корневой запрос выбирает один путь

Если у сервиса несколько исходящих связей с `routing_mode=alternative`,
один корневой запрос идёт **ровно по одной**. При отсутствии весов
каждая альтернатива равновероятна. Пример:
`web → API → {DB_A | DB_B}`. Запрос не удваивается и поэтому
в знаменателе остаётся **одним** клиентским обращением.

Выбор фиксируется двумя независимыми величинами: базовый seed и
номер клиентского запроса, а также идентификатор текущего узла.
Сортировка по identifier исключает зависимость от порядка рёбер в JSON.

## Кэш не обязан каждый раз обращаться к базе

Поддерживается **узкая явно проверяемая схема**:
`web → API → Cache → DB`. Сначала моделируется само обслуживание
кэша. После него каждый клиентский запрос независимо получает
попадание с вероятностью `cache_hit_probability`. При hit путь
заканчивается на Cache, при miss **ровно один** раз продолжается в DB.

На примере времён из C4 (все в секундах): API 0.050,
Cache 0.003, DB 0.020, каждая связь 0.004:

- Hit: `0.004+0.050+0.004+0.003 = 0.061` с прямого пути.
- Miss: `0.061+0.004+0.020 = 0.085` с прямого пути.

Вероятности `0` и `1` позволяют проверить оба варианта
детерминированно. При промежуточных вероятностях используется
отдельный seed по запросу и идентификатору Cache.

Если у Cache нет единственного DB fallback, симуляция
**отклоняет** граф с `invalid_cache_topology`, а не молча
пропускает необходимые вызовы.

## Чего здесь ещё нет

Sync fan-out **не превращается в alternative**: пока он
по-прежнему блокируется до определения обязательности join.
Нет timeout/retry/async, клиентского обратного пути и
статистического вердикта NFR. Исходы и ограничения
очередей из [этапа 5](05-bounded-admission.md) сохраняются.

Результат по-прежнему измеряет **прямой** маршрут,
а не круглое клиентское время ответа. Схемы с несколькими
альтернативными путями допустимы при одном клиентском корне и DAG.

```bash
uv run pytest -m unit tests/unit/architecture_simulation
uv run ruff check .
uv run ruff format --check .
uv run mypy src tests scripts
```
