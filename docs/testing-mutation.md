# Мутационное тестирование (mutmut)

`mutmut` меняет выражения и условия в коде и проверяет, выявляют ли тесты эти ошибки. В отличие от процента покрытия, мутационный анализ помогает оценить содержательность утверждений в тестах.

## Пилотная область

Для первого этапа исследуется `src/domain/models/base_constraints.py`: сравнения порогов, проверка диапазонов и обработка численных требований. Остальной код **пока не проверяется** mutmut; расширять область следует после анализа выживших мутаций.

```bash
uv sync --locked --all-groups
uv run --with mutmut==3.7.0 mutmut run
uv run --with mutmut==3.7.0 mutmut results
```

Запуск требует Linux или WSL (системный вызов `fork`). В GitHub Actions: `Mutation tests`, вручную через `workflow_dispatch` и по понедельникам в 03:00 UTC. Проверка не входит в критический путь каждого PR: число мутаций и время выполнения пока неизвестны.

**Критерий дальнейшего ужесточения:** разобрать выжившие мутации, дополнить независимые поведенческие тесты и только затем включать блокирующий порог на изменения. Эквивалентные мутации могут не обнаруживаться тестами без реального дефекта.

Новый инструмент устанавливается командой `uv run --with` с фиксированной версией без изменения `uv.lock`.
